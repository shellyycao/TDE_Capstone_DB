UPS GL Code Filler

Add your UPS billing file. Get the same file back with column M (GL code) filled in. Your file stays on this computer; nothing is uploaded.

1

Add your UPS file

Drag the UPS .csv file here, or click to choose
Use the file exactly as exported from UPS (no header row). Column M can be empty.

2

Download your results

Your results appear here after you click Fill GL codes.

3

Optional: put your reviewed answers back in

Open the review sheet in Excel, type the right code in the Final_GL column for the rows you checked, and save it as .csv. Then add both files here: the filled file (ending in _GL.csv) and your saved review sheet.
